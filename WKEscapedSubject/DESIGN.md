# 속박: 탈출한 생체 실험자 (Escaped Biological Test Subject)

> 상태: 구현 v0.7.0 (시안 에셋 + 사용자 음원 + 손 모션 시안 적용, v0.6 게임 내 테스트 완료). 남은 것: 속박 아이콘 다듬기 — [plugin/README.md](plugin/README.md)
> 관련 장신구: [생체 실험된](../WKBioExperiment) (이미 구현됨, **같이 낄 수 없음**)

## 1. 기획 요약

| 구분 | 내용 |
|---|---|
| 분류 | 속박 (Binding) |
| 컨셉 | 실험실을 탈출하는 과정에서 신체가 변이된 실험체. 몸은 무겁고 약해졌지만, 극한 상황에서 기괴한 변이 능력을 드러낸다 |
| 손 모양 | 평소에는 원래 손. **변이를 시작한 순간부터 촉수를 다 쓸 때까지** `exotic-infested`(Infested, 핏자국·부글거림) 손 (v0.6.0에서 변경, 처음엔 바퀴벌레 모드처럼 항상 고정) |
| 보상 | 최종 점수 **+35%** |
| 같이 쓸 수 없음 | 장신구 '생체 실험된' |

### 이점과 변이
- **점착성 표면 (패시브)**: 지면에 5초간 머무르면 '굼벵이' 효과가 발현되어 맨손으로도 벽을 오를 수 있다. 발현 후 **벽을 처음 짚는 순간부터 7초** 동안 유지된다 (그 전까지는 줄지 않음).
- **촉수 변이 (조건부 액티브)**: 아래 2장 참고
  - 촉수 상태에서는 일반 손처럼 벽과 손잡이를 잡을 수 있다. 매달려 있는 동안 스태미나가 줄지 않고 오히려 회복된다.

### 페널티
- 인벤토리 용량 **-2칸** (파우치가 아니라 인벤토리 용량 자체를 줄임)
- 중력 **+20%**
- 스태미나 **-20%**
- 스토리 강제: '둥지'의 '어머니'가 실험체를 알아보고 적대한다 (우호 루트 불가)

## 2. 촉수 변이 규칙 (확정)

```
[굼벵이·알약·주사기·Lemon 로치 섭취] → 변이 충전 1회 획득 (중첩 없음)
        ↓
[맨손 + 상호작용 키(손바닥 펴는 동작) 유지] → 5초에 걸쳐 변이 진행
        │  키를 떼면 → 진행만 0초로 초기화 (충전은 유지)
        ↓ 5초 도달
[촉수 손] 바나클 훅 4회 → 우측 하단에 횟수 표시
        ↓ 4회 모두 사용
[원래 손(Infested)으로 복구] 횟수 표시 사라짐, 충전도 소모됨
```

| 상황 | 처리 |
|---|---|
| 충전 없이 키를 누름 | 아무 일도 없음 |
| 이미 충전된 상태에서 또 섭취 | 효과 없음 (중첩 없음) |
| 촉수 상태에서 또 섭취 | 효과 없음 (남은 횟수가 늘지 않음) |
| 변이 도중 키를 뗌 | 손 모양이 원래대로 돌아가고 진행 0초. 충전은 남아 있어서 다시 누르면 처음부터 진행 |
| 변이 도중 물건을 듦 | 맨손이 아니게 되므로 키를 뗀 것과 같게 처리 |

## 3. 게임 코드 확인 결과와 구현 방법

| 기능 | 게임에 있는 것 (확인함) | 구현 방법 |
|---|---|---|
| 속박 등록 | `Trinket.isBinding = true`, `TrinketList.bindings` | '생체 실험된'과 같은 방식으로 런타임 생성 |
| 점수 +35% | `scoreMultiplierBonus` (속박은 `bindingValue`로 합산) | `0.35` |
| 중력 +20% | 버프 `addGravity` (속박 High Gravity가 사용) | `+0.2` |
| 스태미나 -20% | 버프 `addStamina` (`1 + 값`으로 계산) | `-0.2` |
| **인벤토리 -2칸** | 인벤토리 용량 = `(5 + addCapacity) ÷ (1 + divideCapacity)`. 속박 **Half Inventory**가 `divideCapacity`로 용량을 절반으로 줄임 | 버프 `addCapacity = -2` → 기본 5칸이 **3칸**. 넘게 들면 Half Inventory처럼 짐 초과(이동 둔화, 가방 빨간색) 상태가 됨 |
| **손 고정** | 속박 **Roach Mode**가 `PerkModule_PlayerHandCosmeticOverride`로 손을 `Roach` 코스메틱으로 바꿈 | 같은 모듈에 코스메틱 이름 `Infested` |
| 굼벵이 효과 | `HandItem_Buff_Grub`, 버프 `grabAnything` | 굼벵이 버프를 복사해 7초 적용 |
| 매달릴 때 스태미나 회복 | 버프 `regenerateGripStrength`, `addStaminaRegen` | 촉수 상태에서만 켬 |
| 섭취 감지 | 굼벵이·알약·주사기·Lemon 로치 모두 `HandItem_Buff.StartBuff` | '생체 실험된'에서 쓰는 방법 그대로 |
| **같이 쓰기 금지** | 장신구 선택 화면 `UI_TrinketPicker.SelectTrinket` | 한쪽을 고르면 다른 쪽 선택을 자동 해제하고 안내 문구 표시. 게임 시작 시에도 한 번 더 확인 |
| 바나클 훅 4회 | 손 아이템 `Item_Hands_BarnacleHook` = `HandItem_GrapplingHook` | 메커니즘만 옮겨 와서 촉수 손에서 실행 (3-2 참고) |

### 3-1. 어머니 적대 → 열기 지대 추방 (확정)

**둥지에서 열기 지대로 보내는 원래 게임의 판단** (게임 데이터 `sharedassets1.assets`에서 확인)
둥지 입구의 `Player Mover Target` 오브젝트가 플레이어 도착 시 순서대로 검사한다.

| 순서 | 검사 | 결과 |
|---|---|---|
| 1 | `UT_StatChecker`: 이번 판 통계 `grubs-used` (굼벵이를 사용·섭취한 횟수) | 0보다 크면 → 열기 지대 시퀀스 (`Sequence_HotZone`, 애니메이터 `greetings-hotzone:true`) |
| 2 | `UT_CheckFlag`: 이번 판 플래그 `session_sacrificed_grub` (Rho 제단에 굼벵이를 바침) | 켜져 있으면 → 열기 지대 시퀀스 |
| 3 | 둘 다 아님 | 일반(우호) 인사 `greetings-hotzone:false` |

플래그 `session_sacrificed_grub`는 Rho 제단(`ENV_RhoAltar`)이 굼벵이를 받을 때 `UT_CheckFlag.SetFlag("session_sacrificed_grub:true")`로 켠다.

**구현 방법: "이미 굼벵이를 바쳤다"고 속이기** (제안하신 방식)
- 속박의 퍽에 `flags = ["session_sacrificed_grub"]`를 넣는다.
- 퍽은 시작할 때 `flags`에 적힌 플래그를 자동으로 켜는 기능이 이미 있다 (`Perk.Initialize` → `CL_GameManager.SetGameFlag`).
- 따라서 **코드를 추가하지 않고** 데이터 한 줄로 둥지에서 원래 게임의 열기 지대 추방 시퀀스가 재생된다.

| 비교 | `grubs-used` 통계를 올리기 | `session_sacrificed_grub` 플래그 켜기 (채택) |
|---|---|---|
| 둥지 판정 | 열기 지대 | 열기 지대 |
| 부작용 | 굼벵이 관련 업적 집계(`ACH_50GRUBSKILLED` 등)와 통계가 오염됨 | 이 플래그를 읽는 곳은 둥지 판정뿐이라 부작용 없음 |
| 구현 | 코드 필요 | 퍽 데이터 한 줄 |

참고 (원래 게임 동작, 변경 없음):
- 어머니 50m 안에서 굼벵이를 죽이거나 먹거나, 어머니를 3번 때리면 `DEN_Mother.Enrage()` → 6초 뒤 압사(사망). 이건 추방과 별개의 원래 게임 규칙이라 그대로 둔다.
- 따라서 둥지에서 굼벵이로 변이를 충전하는 것은 여전히 위험한 선택이다.

### 3-2. 촉수 사출 (바나클 훅 메커니즘)

#### 원래 바나클 훅 동작 (`HandItem_GrapplingHook`, 게임 코드 확인)
| 단계 | 동작 |
|---|---|
| 조준·누름 | 버튼을 누르고 있으면 `Primed` 상태. 카메라 정면으로 반지름 0.1 구체를 쏴서(`SphereCast`) 최대 `grappleDistance`(기본 20m)까지 검사 |
| 걸림 | 벽에 맞으면 `Latched`. 그 지점으로 플레이어를 당김 (`AddForce`, 힘 곡선 `grappleForceCurve`, `grappleForceTime` 동안) |
| 공중 소모 | 공중에 떠서 끌려가는 동안 훅 자체의 스태미나가 줄고, 0이 되면 놓침 |
| 점프 | 걸린 상태에서 점프하면 놓으면서 위로 튀어 오름 (`ForceJump` + 위쪽 힘) |
| 놓기 | 버튼을 떼면 놓음 (`LetGo`), 0.5초 뒤 다시 쏠 수 있음 |
| 특수 | 음식·각성제를 맞히면 끌어와 먹음(스태미나 회복), 물리 물체는 끌어당김, 버튼은 눌림 |
| 연출 | 3D 혀 메시(`hookMesh`)를 맞은 지점까지 늘리고(`ScaleHookToPosition`), 셰이더 값 `_Wiggle`로 꿈틀거림. 손 애니메이터 상태 `Primed` / `Latched` / `Yoink` / `Drained` |

#### 이 속박에서 쓰는 방식
아이템을 손에 쥐여 주는 대신, **위 메커니즘만 플러그인 안에 옮겨 와서** 촉수 손 상태에서 직접 실행한다. (맨손이어야 벽과 손잡이를 일반 손처럼 잡을 수 있기 때문)

| 항목 | 내용 |
|---|---|
| 횟수 차감 | **벽에 걸리는 데 성공했을 때만** 1회 차감. 빗나가거나 아래의 음식·물체·버튼에 맞으면 차감 없음 |
| 사거리·당기는 힘 | 원래 바나클 훅 프리팹의 값을 런타임에 읽어서 그대로 사용 |
| 훅 스태미나 | 쓰지 않음. 대신 4회 제한. 매달려 있는 동안은 속박 규칙대로 플레이어 스태미나 회복 |
| 음식 끌어오기·물체 당기기·버튼 누르기 | 원래처럼 동작, **횟수 차감 없음** (확정) |
| 점프로 놓기 | 원래처럼 동작 |

**발사 입력 (확정, v0.2.0에서 변경)**: 촉수 상태에서 **맨손 버튼을 2초간 누르고 있으면** 촉수를 쏜다. 누르는 동안 무언가를 잡으면 취소된다. 누르는 동안 손의 촉수가 점점 크게 꿈틀거린다.
- v0.1.0에서는 잡을 곳이 없으면 바로 쐈는데, 아무 클릭에나 촉수가 나가는 문제가 있어 바꿨다.
- 채택 이유: 상호작용 키를 짧게/길게 나누면(안 B), 변이를 하려고 길게 누르려다 이미 충전된 상태인 줄 모르고 짧게 눌러 1회를 날릴 수 있다.
- 상호작용 키는 변이(5초 유지) 전용으로 남긴다.

#### 촉수 사출 연출 (새로 만들 것)
| 구성 | 방식 | 에셋 |
|---|---|---|
| 뻗어 나가는 촉수 | 원래 바나클 훅의 3D 혀 메시와 늘어나는 로직을 재사용하고, 재질만 검은 촉수로 교체 | 촉수 텍스처 1장 (세로로 이어지는 반복 무늬, 끝부분은 갈라진 집게). **색은 손 변이 촉수와 같은 팔레트** (4-6의 본체 `#0A080E`, 광택 `#46285A`, 그늘 `#221628`) — 변이로 손에 드러난 촉수가 그대로 뻗어 나가는 것처럼 보이게 |
| 발사 순간 | 0.12초 동안 메시가 손에서 목표까지 늘어남 (원래는 즉시) + `_Wiggle` 크게. **발사하는 손 앞에서 검은 덩어리 파티클이 터짐** | 없음 (코드) |
| 벽에 닿음 | **닿은 지점에서 면 바깥으로 검은 촉수액 파티클이 튐** (물체·버튼에 닿으면 절반 크기) | 없음 (코드, `TentacleFX.cs`) |
| 걸린 동안 | 팽팽하게 당겨지며 미세하게 꿈틀 | 없음 (코드) |
| 놓을 때 | 0.2초 동안 손으로 말려 들어감 | 없음 (코드) |
| 손 스프라이트 | 촉수 손 세트(`escaped-tentacle`)에 발사 포즈 3종 추가 | 아래 표 |

#### 소리 (확정: 바나클 훅 소리 재사용)
원래 바나클 훅 손 아이템(`Item_Hands_BarnacleHook`)의 소리 묶음(`UT_AudioClipHandler`)을 런타임에 가져와 같은 이름으로 재생한다. 새로 녹음할 소리는 없다.

| 시점 | 소리 이름 | 비고 |
|---|---|---|
| 조준 (누르는 순간) | `grapple:prime` | |
| 벽에 걸림 | `grapple:latch` + 맞은 지점에서 `grapple:latchhit` | 3D 위치 소리 |
| 음식 끌어와 먹음 | `grapple:eat` + `grapple:latch` + `grapple:latchhit` | |
| 놓음 | `grapple:letgo` | |
| 마지막 1회를 쓰고 놓음 | `grapple:hungry` | 원래는 훅 스태미나가 바닥일 때 나는 소리. "촉수가 지쳤다"는 신호로 사용 |

선택 사항: 촉수 느낌을 살리려고 음높이를 약간 낮게(0.85~0.9배) 재생할 수 있다. 플레이 테스트 후 결정.

#### 손 포즈

| 손 포즈 | 시점 | 그림 내용 |
|---|---|---|
| 조준 (`Primed`) | 버튼을 누르는 순간 | 손바닥이 앞을 향해 펼쳐지고 손가락 사이로 촉수 끝이 꿈틀거리며 삐져나옴 (2프레임 반복) |
| 발사·걸림 (`Latched`) | 걸려 있는 동안 | 손바닥 가운데에서 굵은 촉수 다발이 화면 안쪽으로 뻗어 나가는 모습 (3D 메시와 이어지는 시작 부분) |
| 회수 (`Yoink`) | 놓거나 끌어올 때 | 촉수가 손바닥으로 빨려 들어가며 손이 반동으로 젖혀짐 (2~3프레임 1회 재생) |

## 4. 손 변이 에셋 기획

### 4-1. 게임의 손 스프라이트 구조
`White Knuckle_Data/Mods/Cosmetics/Hands/<이름>/` 형식이다.

```
<이름>/
├─ cosmetic-handitem-settings.json   ← 어떤 스프라이트를 무엇으로 바꿀지
├─ card-background.png / card-foreground.png
├─ Sprites/HND_xxxx.png               ← 포즈별 128×128 PNG
└─ Interacts/interact-hand-*.png      ← 상호작용 아이콘 5종
```
- 이름 규칙 `HND_[B|F][1~3][A~D][1~4]`: `B` = 손 본체, `F` = 쥔 물건 앞 손가락
- 덧그림: `secondaryTextures` → `_OverlayMult` (예: `climber-bloodied`) / 통째 교체: `replacementSpriteNames` (예: `exotic-denizen`)

### 4-2. Infested 고정으로 줄어드는 작업량
손이 항상 `exotic-infested`(87장)이므로, **밑그림이 하나로 정해진다.**
- 플레이어마다 다른 기본 손이나 장갑 코스메틱 위에서 어떻게 보일지 신경 쓸 필요가 없다.
- 덧그림을 Infested 스프라이트 위에 정확히 맞춰 그릴 수 있다. 픽셀 단위로 윤곽에 붙여도 된다.
- 각 단계는 **Infested 코스메틱을 복사해서 덧그림만 더한 코스메틱**으로 만든다.

| 코스메틱 | 내용 | 메뉴 노출 |
|---|---|---|
| `Infested` (게임 기본) | 속박 적용 시 기본 손 | 원래대로 |
| `escaped-stage1` | Infested + 손목 촉수 | 숨김 |
| `escaped-stage2` | Infested + 손등까지 촉수 | 숨김 |
| `escaped-stage3` | Infested + 손 전체 촉수 (4초에는 2프레임 맥동) | 숨김 |
| `escaped-tentacle` | 촉수 손 (바나클 모드) | 숨김 |

### 4-3. 5초 타임라인

| 시간 | 손 | 비고 |
|---|---|---|
| 0초 | Infested | 손을 펴고 떨기 시작 (흔들림은 코드로 처리) |
| 1초 | `escaped-stage1` 손목 | 소매 아래에서 촉수 끝이 뚫고 올라옴 |
| 2초 | `escaped-stage2` 손등 | 손가락 시작 부분까지 퍼짐 |
| 3초 | `escaped-stage3` 손 전체 | 손바닥과 손가락 끝까지 |
| 4초 | `escaped-stage3` 맥동 | `framerate`로 2프레임 반복 |
| 5초 | `escaped-tentacle` | 바나클 4회 충전, 우측 하단 표시 등장 |
| 키를 뗌 | Infested | 즉시 원래 손, 진행 0초 |
| 4회 소진 | 3→2→1→Infested | 0.5초 동안 되돌아감 |

### 4-4. 시안 (`concept/`)
- `HND_B1A2_concept_sheet.png`, `HND_B2A1_concept_sheet.png`: Infested 손 위의 0→1→2→3초 단계 (자동 생성 초안)
- `*_stageN_overlay.png`: 게임에 들어갈 형태의 덧그림 레이어 (투명 배경 128×128)

### 4-5. 제작 방식
1. 포즈마다 **3단계(손 전체) 덧그림 한 장만** 그린다. 1·2단계는 `tools/TentacleOverlay.cs`가 손목에서 떨어진 거리를 기준으로 잘라 낸다.
2. 우선순위: 손바닥 펴는 동작(키 유지 중 보이는 포즈)과 매달리기·오르기 대표 포즈 약 12장을 먼저 그린다.
3. 촉수 손 세트는 실루엣 위주로 그린다. `F` 레이어는 촉수 끝만 그린다.

### 4-6. 그림 기준
| 항목 | 기준 |
|---|---|
| 촉수 본체 | `#0A080E` |
| 표면 광택 (위쪽 1px) | `#46285A` |
| 아래 가장자리 그늘 | `#221628` |
| 피부 위 그림자 (오른쪽 아래 1px) | `#5C5862` |
| 굵기 | 손목 4px → 손등 3px → 손가락 끝 2px |
| 빛 방향 | 왼쪽 위 |
| 1~3단계 | Infested 손 윤곽 밖으로 나가지 않기 |
| 촉수 손 세트 | 촉수 끝이 윤곽 밖으로 3~6px 뻗어도 됨 |

## 5. 바나클 횟수 표시 (우측 하단)

| 항목 | 내용 |
|---|---|
| 위치 | 화면 우측 하단 |
| 모양 | 두 갈래 촉수가 서로 꼬인 띠, 4칸 (칸 하나 = 꼬임 한 번) |
| 등장 | 변이 5초를 채운 순간 4칸으로 나타남 |
| 사용 | 바나클 훅을 쓸 때마다 오른쪽 칸부터 하나씩 사라짐 |
| 0회 | 표시 자체가 사라짐 |
| 다시 등장 | 다음에 변이 조건을 달성하면 다시 4칸으로 표시 |

시안 (`concept/ui/`):
- `barnacle_counter_sheet.png`: 4 → 3 → 2 → 1 → 0 상태 비교 (4배 확대)
- `barnacle_counter_0~4.png`: 실제 크기 (91×28px) 이미지
- 도구: `tools/BarnacleCounterIcon.cs`

추천 연출: 칸이 사라질 때 0.2초 동안 칸이 끊어지듯 흔들린 뒤 사라짐. 마지막 칸이 사라지면 손 복구 연출과 동시에 진행.

## 6. 결정 사항 기록

### 해결된 사항
- **촉수 발사 입력**: 안 A (닿는 곳에 잡을 곳이 없으면 발사) (3-2)
- **음식 끌어오기·물체 당기기·버튼 누르기**: 허용, 횟수 차감 없음 (3-2)
- **촉수 소리**: 바나클 훅 소리 재사용 (3-2)
- **사출 촉수 색**: 손 변이 촉수와 같은 검은 팔레트 (3-2, 4-6)
- **열기 지대로 보내는 방법**: 속박 퍽 플래그 `session_sacrificed_grub`로 해결 (3-1)
- **맨손에 바나클 훅 붙이기**: 아이템 대신 메커니즘을 옮겨 와서 실행 (3-2)
- **손 코스메틱이 다음 판에 남는지**: 남지 않는다. 손 고정(`LoadHandCosmetic`)은 그 판의 플레이어 손 목록(`currentCosmetics`)에만 추가되고 설정 파일에는 저장되지 않는다. 따로 되돌리는 처리는 필요 없다.
- 단, 손 목록은 **추가** 방식이라 변이 단계를 바꿀 때는 목록을 비운 뒤 새 단계를 넣어야 한다 (`removeCosmetics`와 같은 처리). 그러지 않으면 단계가 겹쳐 쌓인다.
