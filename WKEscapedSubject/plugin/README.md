# 탈출한 생체 실험자 - 플러그인 (v0.9.3, 시안 에셋)

기획: [../DESIGN.md](../DESIGN.md)

## 빌드
```
dotnet build -c Release                 # 빌드 + 게임 폴더 배포
dotnet build -c Release -p:Deploy=false # 빌드만
```
배포 위치: `BepInEx\plugins\WKEscapedSubject\` (DLL + `Assets\`)
게임에서 빼려면 이 폴더를 지우면 된다.

## 구현된 것
| 기능 | 파일 |
|---|---|
| 속박 등록, 점수 +35%, 체력 -20%, 이동속도 -20%, 중력 +20%, 스태미나 -20%, 인벤토리 용량 -2 | `BindingFactory.cs` |
| 손: 평소에는 원래 손, 변이를 시작한 순간부터 촉수를 다 쓸 때까지 Infested(핏자국·부글거림) | `HandSkin.cs` |
| 둥지 열기 지대 추방 (플래그 `session_sacrificed_grub`) | `BindingFactory.cs` |
| '생체 실험된'과 같이 고르기 금지 | `Patches.cs` |
| 굼벵이·알약·주사기·Lemon 로치 섭취 → 변이 충전 (중첩 없음) | `Patches.cs`, `MutationController.cs` |
| 맨손 버튼을 뻗고 5초 → 손목·손등·손 전체·꿈틀 → 촉수 (떼면 처음부터) | `MutationController.cs`, `HandOverlay.cs` |
| 촉수 사출 5회 (맨손 버튼 0.75초 유지 시 발사, 당기는 힘 +5%, 버튼을 누르는 동안 유지, 박힌 곳 가까이에서 맨벽 잡기, 사거리 30m, 손바닥에서 발사, 벽에 걸릴 때만 차감, 바나클 훅 값·소리 재사용) | `TentacleGrapple.cs` |
| 촉수 파티클: 발사하는 손에서 검은 덩어리, 벽에 닿은 곳에서 검은 촉수액 | `TentacleFX.cs` |
| 촉수 상태 동안 스태미나 +35% (사출 횟수를 다 쓰면 사라짐) | `MutationController.cs` |
| 소리: 변이 충전(`mutation_charge.wav`), 촉수 발사 대기(`tentacle_shoot.wav`) | `Sounds.cs` |
| 점착성 표면: 지면 5초 → 굼벵이 효과 발현(대기, 보라색 화면) → 벽을 짚는 순간부터 7초, 처음 5초 스태미나 감소 없음 | `MutationController.cs` |
| 우측 하단 횟수 표시 | `MutationController.cs`, `Assets/UI` |

## 임시 에셋 (`Assets/`)
- `Overlays/stage1~16/`: Infested 손 87장 × 16프레임 촉수 덧그림 (5초 변이 동안 차례로 재생) (`tools/TentacleOverlay.cs`로 자동 생성)
- `UI/barnacle_counter_0~5.png`: 횟수 표시 (5칸)
- `Sounds/mutation_charge.wav`(Slime Movement, CC BY 4.0), `Sounds/tentacle_shoot.wav`(Splat_05, CC BY 4.0): `sample_sounds/WK_ES`의 음원을 16bit WAV로 변환
- `binding_icon.png`: 게임 속박 아이콘 형식 32px (`tools/binding_icon_32.py`로 `concept/binding_icon_128.png`에서 생성)

정식 그림이 나오면 같은 이름으로 덮어쓰면 된다.
